# Тест-кейс: зміна мови інтерфейсу Wikipedia

**ID:** WIKI-UI-LANGUAGE-001  
**Назва:** Успішна зміна мови інтерфейсу з англійської на українську авторизованим користувачем  
**Тип:** Functional

## Передумови

- Користувач має обліковий запис Wikipedia і може авторизуватися.
- Мова користувача - Англійська
- Сайт доступний за адресою `https://en.wikipedia.org/wiki/Main_Page`.
- Для автотесту задані `WIKIPEDIA_USERNAME` і `WIKIPEDIA_PASSWORD` у файлі `.env`.

## Кроки та очікуваний результат

| Крок | Дія | Очікуваний результат |
| --- | --- | --- |
| 1 | Відкрити головну сторінку Wikipedia та авторизуватися, якщо користувач ще не авторизований. | Відображається головна сторінка; користувач авторизований. |
| 2 | Відкрити меню користувача та перейти до **Preferences**. | Відкривається сторінка налаштувань профілю користувача. |
| 3 | У вкладці **User profile** знайти розділ **Internationalisation**. | Відображається налаштування мови інтерфейсу. |
| 4 | Вибрати українську мову інтерфейсу та зберегти зміни. | Налаштування збережене зі значенням мови `uk`. |
| 5 | Повернутися на головну сторінку Wikipedia. | Елементи інтерфейсу та пошуку відображаються українською. |
| 6 | Повторно відкрити головну сторінку в новому контексті зі збереженим станом авторизації. | Українська мова інтерфейсу збереглася після повторного відкриття. |

**Підсумковий результат:** авторизований користувач успішно змінює мову інтерфейсу на українську; вибір збережений.

**Автоматизація:** [e2e/wikipedia-language.spec.ts](e2e/wikipedia-language.spec.ts)

**Запуск у Docker:** `docker compose run --build --rm playwright`

HTML-звіт створюється Playwright у `playwright-report/index.html`; Docker Compose монтує цю папку з контейнера до папки хоста.
