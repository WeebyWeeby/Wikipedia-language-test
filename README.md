# Wikipedia-language-test

Автоматизований наскрізний тест на Playwright і TypeScript для зміни мови інтерфейсу авторизованого користувача Wikipedia. Проєкт підтримує запуск у Docker і збереження HTML-звіту на хості.

## Запуск тестів Playwright

**Передумови**
- **Node.js**: встановлена версія 20 або новіша.
- **Робоча папка**: відкрийте кореневу папку проєкту та виконуйте команди з неї.

**Встановлення залежностей (Запуск через Docker встановлює їх самостійно)**
- **Встановити npm-пакети:**
  - `npm install`
- **Встановити браузери Playwright:**
  - `npx playwright install`
- **Встановити браузери разом із системними залежностями (Linux CI):**
  - `npx playwright install --with-deps`

**Основні команди**
- **Запустити тест Wikipedia локально:** `npm run test:chromium`
- **Запустити браузер у видимому режимі:** `npm run test:chromium -- --headed`
- **Відкрити HTML-звіт:** `npx playwright show-report`

**Змінні середовища для тесту**
- `WIKIPEDIA_USERNAME` — ім'я користувача Wikipedia
- `WIKIPEDIA_PASSWORD` — пароль користувача Wikipedia

**Результати тесту**
- За замовчуванням Playwright зберігає HTML-звіт у `playwright-report/index.html`. Щоб відкрити його, виконайте `npx playwright show-report`.

## Тест зміни мови інтерфейсу Wikipedia

Перед запуском переконайтеся, що мова профілю Wikipedia встановлена англійською: тест перевіряє перемикання інтерфейсу з англійської на українську.

## Запуск вручну

Скопіюйте `.env.example` у файл `.env` і вкажіть у ньому ім'я користувача та пароль Wikipedia. Потім запустіть команду `npx playwright test e2e/wikipedia-language.spec.ts --project=chromium`. Тест авторизується, перевіряє зміну мови інтерфейсу на українську та залишає цю мову встановленою в профілі. Перед повторним запуском встановіть англійську мову профілю знову.
 
## Запуск у Docker

Встановіть Docker Desktop, скопіюйте `.env.example` у `.env` і вкажіть облікові дані Wikipedia.  Щоб зібрати образ і запустити тест у Chromium, запустіть **Docker Desktop App** та виконайте:

```sh
docker compose run --build --rm playwright
```

Контейнер використовує образ Playwright версії `1.62.1`, запускає браузер у headless-режимі та зберігає HTML-звіт і результати тесту у робочій папці на комп'ютері. Команда повертає код завершення тесту. Облікові дані передаються контейнеру під час запуску й не копіюються до образу. Без облікових даних тест Wikipedia буде пропущено.

Після запуску звіт буде в папці `playwright-report`, файл `playwright-report/index.html`. Відкрийте цей файл у браузері або, або виконайте `npx playwright show-report` з папки проєкту.

Тест-кейс, передумови й очікувані результати описані у файлі [TEST-CASE.md](TEST-CASE.md).
